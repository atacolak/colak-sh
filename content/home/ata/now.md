# now

late 2026.
the live thread is a village of persistent engineering actors, plus the speech and browser seams that feed it.

## actor village

persistent leads for running multiple projects without making the operator the message bus.
each lead owns a beads ledger, a cockpit pane, and a mailbox.
independent work mints a sibling.
workers stay ephemeral.

the public artifact is `projects/actor-village.md`.
there is no standalone github repo.
the pieces that are public are linked from that page: the omp fork, hcom, systemd-ops, mardi-gras, speech-core.

## speech-core / talker

speech-in still closes immutable turns.
speech-out is a separate mouth.
talker is the spoken attention consumer for the village: what is going on, what is waiting on ata, without turning the operator into a router.
voicecat remains the phone line.
